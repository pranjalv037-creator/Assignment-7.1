Assignment 7.1 — Responsive Navigation Bar

Aim

To create a responsive horizontal navigation bar using CSS Flexbox with a logo, navigation links, and a button.

Flexbox Properties Used

- "display: flex" — Arranges items in a flexible layout.
- "justify-content: space-between" — Distributes items with space between them.
- "align-items: center" — Aligns items vertically.
- "flex-wrap: wrap" — Allows items to move onto another line when needed.
- "gap" — Sets spacing between items.

Features

- Logo and navigation links.
- Get Started button.
- Hover effects on navigation links and buttons.
- Responsive layout using a media query for smaller screens.
- Multiple sections linked through navigation.

Files Included

- "index.html" — HTML structure of the navigation bar and webpage.
- "style.css" — Flexbox styling and responsive layout.
